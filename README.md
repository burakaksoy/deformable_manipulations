# Collaborative Manipulation of Deformable Objects 
This repository includes the implementation of 
- B. Aksoy, J. T. Wen, “Collaborative Manipulation of Deformable Objects with Predictive Obstacle Avoidance”,
2024 IEEE International Conference on Robotics and Automation (ICRA), 2024.
- B. Aksoy, J. T. Wen, “Planning and Control for Deformable Linear Objects,” submitted to IEEE Transactions on
Automation Science and Engineering (T-ASE), 2025. [ArXiv Preprint: arXiv:2503.04007].
- B. Aksoy, J. T. Wen, “Collaborative Human-Robot Manipulation for Composite Layup Applications”, to be submitted

## Installation
On a ROS Noetic installed Ubuntu 20.04, download and run `install.bash`. 

It creates `catkin_ws_deformable` workspace in your `home` directory, clones the related repositories, and installs.
